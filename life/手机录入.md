# 安卓手机录入设置

> 目标：锁屏/桌面点一下 → 选领域 → 填数值 → 15 秒写完，自动进 Obsidian，自动进 GitHub。
> 用 `MacroDroid`（免费版够用）。不装服务器、不装新同步工具。

---

## 第 0 步：先确认库名（别跳过，错了整条链断）

打开手机 Obsidian → 左上角切库的地方 → 记住显示的名字。

本文假设它是 `Personal-Knowledge-Base`。**手机上的库文件夹名必须和电脑一致**，否则 URI 找不到库，什么都不会发生。

---

## 第 1 步：装 MacroDroid，建一个宏

新建宏 → 名字填 `记一下`。

### 触发器

选 **快捷方式/Shortcut**（这样它会出现在桌面长按菜单和通知栏里）。
再复制一份触发器为 **小组件点击**（可选，看你习惯）。

### 动作序列（顺序不能乱）

| 顺序 | 动作 | 配置 |
| --- | --- | --- |
| 1 | 询问用户 → **多项选择对话框** | 标题"记什么"，选项加：`体重`、`饮食`、`睡眠`、`情绪`、`学习`、`消费`。结果存到变量 `域` |
| 2 | 询问用户 → **输入对话框** | 标题"数值"，存到变量 `值`。提示语写"例如 72.4 kg / 6.5 h / 7/10" |
| 3 | 询问用户 → **输入对话框** | 标题"备注（可空）"，存到变量 `注` |
| 4 | 变量 → **设置变量** | 变量 `行`，值见下方「拼接串」 |
| 5 | 应用/系统 → **发送 Intent** | 见下方「Intent 参数」 |

### 拼接串（动作 4 的值）

```
- {hour}:{minute} | {域} | {值} | {注}
```

时间变量用魔法文本里的「当前时间 → 小时 / 分钟」。MacroDroid 的 `{hour}` 可能不补零，中午 9:05 会变成 `9:5`——脚本能解析，不用管。

### Intent 参数（动作 5）

| 字段 | 值 |
| --- | --- |
| Action | `android.intent.action.VIEW` |
| Data / URI | 见下 |
| Package | 留空 |
| Flags | 留空 |

Data 填这一整行（`{...}` 是 Magic Text 变量，天/月/年也用魔法文本插入，格式 `yyyy-MM-dd`）：

```
obsidian://new?vault=Personal-Knowledge-Base&file=life/inbox/2026-11-25&append=true&content=- {hour}:{minute} | {域} | {值} | {注}
```

⚠️ 如果 MacroDroid 里只有「打开网站」而没有「发送 Intent」，**别用「打开网站」**——部分版本会给没有协议的字符串补 `http://`，或者交给浏览器处理。宁可用下面的 Termux 方案。

---

## 第 2 步：三个必踩的坑

1. **`content` 里不能有 `&` `#` `%` `+`**
   URI 靠 `&` 分段。备注写成"面试&复盘"会把后半截变成新的参数，写入失败或残缺。
   → 规则：备注里用「和」「、」代替 `&`，用「号」代替 `#`。数值里别用 `+`。

2. **第一次用之前，先在手机上手动打开一次 Obsidian**
   Android 有时会把后台被杀的 App 的 Intent 丢掉。打开过一次之后就不用管了。

3. **手机只写 `inbox/`，电脑只写 `data/`**
   这是分工，也是防冲突的关键：两端永远不会同时改同一个文件，git 就不会打架。
   - 手机：只会往 `life/inbox/YYYY-MM-DD.md` 末尾追加
   - 电脑：只读 inbox，只写 `life/data/*.jsonl`
   - **不要**在电脑上编辑 inbox 文件，**不要**在手机上打开 data 目录

---

## 第 3 步：测一下

1. 桌面长按 → 找到「记一下」快捷方式 → 点
2. 选「体重」→ 填 `72.4 kg` → 备注留空
3. 手机 Obsidian 打开 `life/inbox/日期.md`，应该多一行：

```
- 16:52 | 体重 | 72.4 kg |
```

4. 等 obsidian-git 提交（或手动点同步）→ 电脑上 `git pull` → 跑：

```bash
python life/scripts/life.py ingest
python life/scripts/life.py today
```

看到 `07:20 体重：72.4 kg` 就通了。

## 备选方案：Termux（零编码问题，但要装东西）

适合你后面想要"一条命令记一批"的时候。MacroDroid 走 URI 编码的坑它全都没有。

### 准备

- 装 Termux 和 Termux:Widget
- 给 Termux 存储权限：`termux-setup-storage`
- 确认库的真实路径：

```bash
ls ~/storage/shared/Documents/ | grep -i personal
# 假设输出 Personal-Knowledge-Base
```

### 脚本 `~/bin/记.sh`

```bash
#!/data/data/com.termux/files/usr/bin/bash
VAULT=~/storage/shared/Documents/Personal-Knowledge-Base
DAY=$(date +%Y-%m-%d)
FILE="$VAULT/life/inbox/$DAY.md"
mkdir -p "$VAULT/life/inbox"
[ -f "$FILE" ] || printf '# %s 随手记\n\n' "$DAY" > "$FILE"
read -r -p "领域(体重/饮食/睡眠/情绪/学习/消费): " dom
read -r -p "数值: " val
read -r -p "备注(可空): " note
printf -- '- %s | %s | %s | %s\n' "$(date +%H:%M)" "$dom" "$val" "$note" >> "$FILE"
echo "已写入 $FILE"
# 让 Obsidian 重新读这个文件，顺便让 git 插件看到变化
am start -d "obsidian://open?vault=Personal-Knowledge-Base&file=life/inbox/$DAY" >/dev/null 2>&1
```

```bash
chmod +x ~/bin/记.sh
```

然后 Termux:Widget 建一个 `~/.shortcuts/` 里的软链，桌面小组件点一下就进输入界面。

> 路径因手机而异：有的在 `/storage/emulated/0/Documents/`，有的在 `Android/data/md.obsidian/files/`。上面 `ls` 那步就是为了确认。

## 电脑端配套

```bash
cd Personal-Knowledge-Base
git pull
python life/scripts/life.py ingest    # inbox → data/*.jsonl，幂等
python life/scripts/life.py week      # 生成周报
```

`ingest` 可以反复跑，已经入过库的行会被跳过，所以不用记"处理到哪了"。
