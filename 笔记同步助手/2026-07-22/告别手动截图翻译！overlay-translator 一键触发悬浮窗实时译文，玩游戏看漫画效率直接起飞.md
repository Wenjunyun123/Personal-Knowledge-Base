告别手动截图翻译！overlay-translator 一键触发悬浮窗实时译文，玩游戏看漫画效率直接起飞

玩日服游戏、看日漫总被语言卡住？想实时看懂对话和UI却不想ROOT手机？手动截图翻译又麻烦又断片？😭

今天分享神器 overlay-translator（屏译），一个开源的 Android 实时屏幕翻译工具！无需 ROOT，通过悬浮窗直接在原画面上��加中文翻译，支持游戏、视觉小说、日漫等多种场景，还能离线使用，真正做到“看即译”。🔥

📌 悬浮球一键触发：单击全屏翻译，长按弹出菜单切换模式、语言和预设

📌 多 OCR + 翻译引擎：支持 ML Kit、PaddleOCR、日漫专用 OCR，以及 DeepSeek、DeepL、离线 LLM 等多种翻译方式

📌 悬浮窗实时叠加：译文紧贴原文显示，可拖拽、锁定，支持竖排日漫和长文本滚动

📌 划词翻译增强：框选单词显示译文、音标、释义和例句

📌 完全离线可用：支持端侧 OCR 和本地 LLM，隐私安全无上传

📌 高度可定制：配置可导出，支持预设方案和 API Key 管理

使用方法超级简单！从 GitHub下载 APK 安装，授予悬浮窗和通知权限后启动，首次使用授权截屏服务。在目标 App（如游戏、漫画阅读器）中点击悬浮球即可触发翻译，长按菜单可快速切换设置。
