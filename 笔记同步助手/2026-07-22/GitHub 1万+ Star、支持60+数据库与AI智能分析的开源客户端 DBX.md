## 项目概览

DBX 是一款开源的数据库客户端工具，在 GitHub 上 Star 数已突破 1 万+。它的主要特点包括：

-   **多数据库支持**：官方支持 60+ 种数据库，覆盖常见数据库操作场景。
-   **AI 智能分析**：内置 AI 助手，支持自然语言生成 SQL、自动生成报表与数据分析。
-   **跨平台**：可安装在 macOS、Windows、Linux 系统上。
-   **Docker 部署**：支持通过 Docker / Compose 方式部署。
-   **MCP 集成**：提供 MCP 集成能力，便于与外部工具联动。
-   **运维面板**：附带 Linux 运维面板，便于服务管理。

## 安装与部署

视频演示的部署流程：

1.  在应用商店中搜索项目名称并安装。
2.  配置一个访问密码，用于登录管理后台。
3.  打开 4224 端口用于外部访问（默认监听端口为 4224）。
4.  底层也是通过 Docker 来部署，可打开 Compose 文件确认。
5.  若 Docker 镜像不是最新版，可手动将镜像 tag 改为 latest 后重新部署。

安装完成后，在浏览器访问 `服务器IP:4224` 即可打开登录界面，输入访问密码后即可登录。

## 数据库连接体验

登录成功后，点击「新建连接」可以看到 DBX 支持非常多的数据库类型，官方宣传为 60+ 种，覆盖主流关系型与部分非关系型数据库。常见的数据库操作（建表、查询、编辑数据等）功能都比较通用，可直接使用。

## AI 功能体验

DBX 的 AI 助手入口在界面右上角的机器人头像，点击即可调出。在使用 AI 功能前，需要先配置一个大模型：

1.  新增配置，选择提供商（或使用自定义）。
2.  填入 API Key 与 Endpoint。
3.  选择模型，并进行连通性测试。
4.  测试通过后保存应用即可。

![[笔记同步助手/images/93a87fa1ab8a89004fa6075295818e3a_MD5.jpg|DBX AI 助手配置界面，填写 API Key、Endpoint、模型并测试连通性]]

DBX AI 助手配置界面，填写 API Key、Endpoint、模型并测试连通性

### Ask 模式：自然语言转 SQL

选择目标数据库后，直接向 AI 提问一个查询排序问题，AI 会自动整理出一条 SQL 语句并执行，返回查询结果。这一模式可以显著提升 SQL 编写效率。

### Agent 模式：自动报表与维度分析

将模式切换为 Agent 后，同样一个问题，AI 的产出完全不同：

-   直接生成一份完整的报表。
-   给出要点总结。
-   自动分析出用户可能关注的业务维度。

Agent 模式支持连续对话，可以围绕同一份数据持续追问、深入分析。

![[笔记同步助手/images/162b7d2bc73427455e62ddef74de4594_MD5.jpg|DBX Agent 模式输出，包含报表、要点总结与维度分析]]

DBX Agent 模式输出，包含报表、要点总结与维度分析

## 小结

DBX 的核心亮点在于：

-   用一套客户端管理 60+ 种数据库，减少工具切换成本。
-   AI Ask 模式降低 SQL 编写门槛，适合日常查询。
-   AI Agent 模式适合需要快速产出报表、洞察与维度分析的场景。
-   支持 Docker 部署与跨平台，便于在个人或团队环境中快速搭建。
