## 核心工作流

这些项目可以组合成一套 AI 辅助的视频创作流程：由 Codex 或 Claude 编写与控制代码，再结合图像生成、音频、三维建模、视觉特效和网页渲染，完成从概念到成片的制作。

These projects can form an AI-assisted video production workflow: Codex or Claude writes and controls the code, while image generation, audio, 3D modeling, visual effects, and browser rendering are combined to move from concept to finished video.

## 视频与动画生成项目

### Huashu Motion

用于制作电影感产品宣传视频，甚至能够自行生成配套音乐。

Huashu Motion creates cinematic product-promotion videos and can even prepare the accompanying music.

### Anything2Explainer

输入一个主题，即可生成带配音的解释型视频。

Anything2Explainer turns a topic into an explainer video with voice narration.

### OpenScreen

用于制作具有专业产品演示质感的屏幕录制内容。

OpenScreen produces screen recordings that look like polished professional product demos.

### OneTake

生成不切分场景、由单一连续运镜推进的电影感动画。

OneTake generates cinematic animations that progress through a single continuous camera movement without cutting between scenes.

### Lemo-Opuscar

提供 99 种可由 Codex 或 Claude 通过代码实现的电影感视觉风格。

Lemo-Opuscar offers 99 cinematic visual styles that Codex or Claude can implement through code.

### HyperFrames

通过 HTML 创建动画，并将成果导出为视频。

HyperFrames creates animations with HTML and exports the result as a video.

### Remotion

使用 React 创建和编辑视频、动态信息图与动画内容。

Remotion uses React to create and edit videos, animated infographics, and motion content.

### Remotion Skills

面向 Codex 和 Claude 的现成技能，用于指导其按照正确方法使用 Remotion 制作视频。

Remotion Skills provides ready-made guidance for Codex and Claude on producing videos with Remotion using the correct approach.

用于构建网页动画和运动场景的强大 JavaScript 动画库。

GSAP is a powerful JavaScript animation library for web animations and moving scenes.

### Three.js

Three.js can create 3D scenes, animations, and cinematic camera movements directly in the browser.

### Blender MCP

Blender MCP connects Claude or Codex to Blender so that AI can control 3D scenes.

ComfyUI combines AI-generated visuals and different models through node-based workflows.

## 学习与使用建议

-   先根据目标选择工具：宣传片、讲解视频、网页动画、三维场景和专业视频分别对应不同项目。
-   把 Codex 或 Claude 作为代码生成与流程控制层，通过 MCP、HTML、React 或 Blender 接口连接具体创作工具。
-   先完成低成本的风格测试，再集中处理镜头连续性、动态信息图、音画同步与最终导出。
-   将项目链接加入个人知识库，并记录每项工具的适用场景、输入输出形式和局限，便于后续复用。

Begin by matching a tool to the goal: promos, explainer videos, web animation, 3D scenes, and professional video production each call for a different stack. Treat Codex or Claude as the code-generation and workflow-control layer, connecting creative tools through MCP, HTML, React, or Blender interfaces. Test styles cheaply first, then focus on continuity, motion graphics, audiovisual synchronization, and final export. Save the project links in a personal knowledge base and record each tool's use case, inputs, outputs, and limitations.
