## 项目概览

开源项目 **fast-anything** 号称只需一条命令，就能让程序性能提升 116 倍。它并不要求重写整个项目，而是自动定位其中最慢的 5% 代码，针对关键部分进行优化。

## 工作流程

1.  自动识别项目中性能最差的 5% 核心代码。
2.  录制核心代码约 500 次真实调用，收集具有代表性的运行数据。
3.  将待优化代码及调用数据交给 Claude Code 或 Codex 等编程代理，由其使用 Rust 重新实现。
4.  自动回放真实数据，并执行极端测试，对新旧实现进行验证。

## 验证与安全机制

只有当新实现与原实现的测试结果一致、并且确认性能得到提升时，系统才会允许替换原有代码。如果优化结果不理想，则不会采用替换方案；同时，项目还支持一键回滚，降低自动化改写带来的风险。

## 核心特点

-   只优化最慢的 5% 代码，避免对整个项目进行重写。
-   结合真实调用录制、自动化回放和极端测试验证优化效果。
-   以结果一致性和实际性能提升作为代码替换条件。
-   提供一键回滚机制，保证优化过程可控。
