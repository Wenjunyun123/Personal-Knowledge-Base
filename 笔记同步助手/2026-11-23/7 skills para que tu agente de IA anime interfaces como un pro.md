# 7 skills para que tu agente de IA anime interfaces como un pro

## 7 skills para que tu agente de IA anime interfaces como un pro

1.  **Prompt Motion**  
    [https://t.co/WafB4AWs6w](https://t.co/WafB4AWs6w)  
    Escribes HTML y el agente lo renderiza en vídeo.
    
2.  **Remotion Agent Skills**  
    [https://t.co/AODrRK8hk5](https://t.co/AODrRK8hk5)  
    Skills de animación de Emil Kowalski para trabajar con proyectos de Remotion. Incluyen buenas prácticas y son útiles para agentes como Claude Code, Codex, Cursor, Gemini CLI y OpenCode.
    
3.  **HyperFrames**  
    [https://t.co/AZF5SkH3Fa](https://t.co/AZF5SkH3Fa)  
    Componentes animados listos para pasar a Claude o Codex.
    
    HyperFrames es un editor de vídeo gratuito y de código abierto basado en IA. El resultado es un proyecto real que puedes modificar: cambiar los datos y editar el archivo directamente.
    
    -   Available skills: 19
    -   Los skills están ordenados según el orden en el que los usarías en un proyecto real.
    -   Antes de construir: aprende los términos adecuados, elige con qué construirlo y compara opciones reales antes de decidir.
4.  **Vídeos hechos con React**  
    [https://t.co/QqSfUbs2iG](https://t.co/QqSfUbs2iG)  
    Skills para crear y editar vídeos con React. Los recursos están organizados según el orden natural de trabajo dentro de un proyecto.
    
5.  **Flujos de Blender convertidos en skills para agentes**  
    [https://t.co/MOntfhcdgP](https://t.co/MOntfhcdgP)  
    Flujos de trabajo de Blender convertidos en skills que los agentes de IA pueden utilizar.
    
6.  **Transiciones de layout y animaciones con muelle**  
    [https://t.co/eD98P59e0M](https://t.co/eD98P59e0M)  
    Transiciones entre layouts y animaciones con física de muelle.
    
7.  **Explicaciones animadas a base de código**  
    [https://t.co/aU5XpvK0kD](https://t.co/aU5XpvK0kD)  
    La idea central: **“I MAKE THINGS MOVE.”** Tu agente escribe el código y la explicación se convierte en una animación.
    

### Antes de construir

-   Aprende las palabras y concepts adecuados.
-   Elige las herramientas con las que vas a construir.
-   Crea acciones reales antes de terminar el proyecto.
-   Compara las opciones disponibles antes de decidir.
-   Lee el texto de la forma correcta: **“The right way to read the text is to read the right way to read the text.”**
