本周GitHub神级项目🤯🤯👍  
  
第一名一个月涨了4w6  
  
光是治AI审美的就占了三个：  
  
1. 第一名VoiceStudio  
一个月涨了四万六，总量十一万  
本地AI配音工作室  
它是一个装在你自己电脑上的AI配音工作室，录一段干净的人声就能克隆出同一个音色，用一句话描述还能凭空设计一个新声音，给视频翻译配音、听写、转文字、读有声书，六百四十六种语言都能做，免费本地跑，不用注册账号。作者也提醒了，克隆别人的声音要先拿到本人同意。  
GitHub链接：[github.com/debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio)  
2. 第二名是Cloudflare开源的security-audit  
一个月涨了四万三  
一句话就能让你的AI变成一个安全审计团队  
它先摸清整个项目的结构，再派出好几个独立的Agent分头去找漏洞，每找到一个就交给一个全新的Agent专门想办法推翻它，最后出一份报告，分成已确认、待验证、已排除三类。  
GitHub链接：[github.com/cloudflare/security-audit-…](https://github.com/cloudflare/security-audit-skill)  
3. 第三名Matt Pocock的Skills  
一个月涨了三万四，总量三十二万  
TypeScript名师的AI技能  
作者是TypeScript圈很有名的老师，这是他每天写真项目在用的一整套AI技能。最火的一个叫grill-me，开工之前让AI反过来一条条拷问你到底想要什么，对齐了再动手。Codex一行命令就能装。  
GitHub链接：[github.com/mattpocock/skills](https://github.com/mattpocock/skills)  
4. 第四名Orca  
一个月涨了三万三，总量十二万五  
AI编程工作台，一次开一队Agent  
它是专门给AI编程用的工作台，Claude Code、Codex这些Agent可以同时开起来，每个Agent一个独立工作区，区里干活互不打架。一个大任务交给它，它会自己拆活，派几个Agent分头去做，再把结果收回来交给你。  
GitHub链接：[github.com/stablyai/orca](https://github.com/stablyai/orca)  
5. 第五名T3 Code  
一个月涨了将近三万三，总量六万一  
一个界面遥控各家编程AI  
你电脑上的Claude Code、Codex、Cursor，全都接进一个界面，用的就是你自己的订阅。在电脑上开一个任务，人出门了，掏出手机就能批准AI的下一步，手机上一键批准。  
GitHub链接：[github.com/pingdotgg/t3code](https://github.com/pingdotgg/t3code)  
6. 第六名Impeccable  
一个月涨了两万九，总量十一万  
治AI做网页的审美  
第一个治AI审美的，Inter字体、紫到蓝的渐变、卡片里面再套卡片，这些一看就是AI做的网页它都认得。觉得太平淡就说bolder，太花哨就说quieter。它还带了六十二条检查规则，不用大模型，直接把AI味扫出来。  
GitHub链接：[github.com/pbakaus/impeccable](https://github.com/pbakaus/impeccable)  
7. 第七名Hallmark  
一个月涨了两万五，来自Together AI  
第二个治AI审美的  
它备好了五十套设计主题，纸张、字体、配色、质感全都配好，再按你的网页要干什么来排版，做完还会打开真的浏览器挨个检查。已经做好的网页也能救，一句hallmark redesign，内容不动，只换设计。  
GitHub链接：[github.com/nutlope/hallmark](https://github.com/nutlope/hallmark)  
8. 第八名agent-desktop  
一个月涨了两万二，出自Vercel的实验室  
它让AI直接操作你电脑上的软件，不靠截图认图，而是读出软件里每一个按钮、每个元素，一个编号，AI说点几号就点几号，点完再读一遍确认点对了没有。Mac、Windows、Linux都能用。  
GitHub链接：[github.com/vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop)  
9. 第九名HyperFrames  
一个月涨了两万一，总量八万五，出自HeyGen  
写网页出视频  
出自做数字人的HeyGen，它的口号就一句：写网页出视频，专门给AI用。装上它的技能，跟Claude Code说一句想要什么视频，AI自己写页面、加动画、配素材，直接导出MP4，还有免费的桌面版。  
GitHub链接：[github.com/heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)  
10. 第十名taste-skill  
一个月涨了两万，总量十一万六  
给AI的设计品味  
第三个治AI审美的，让AI做公司官网，它能做到Figma、[x.xn--ai,,,-ig1ha74au0yqsau5qswl33nyk…](http://x.ai那个水准，一屏一块内容，左右对得整整齐齐，用的是真实照片。做完先在真的浏览器里，用电脑、平板、手机好几种宽度检查一遍，过了才交给你。)  
GitHub链接：[github.com/Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
