## 核心观点：把 Coding Agent 当成老师

不只把 Coding Agent 当作工程师，也把它当作老师——它能解释代码库结构、帮你变得更 technical。视频中，作者分享了如何让 Claude Code 把一个完整的代码库做成交互式可视化网页，把所有技术用大白话讲清楚。

### 案例产品：Excalidraw Record

作者最近发布了一款录屏产品 Excalidraw Record，整款产品全程由 Claude Code 完成开发。开发完成后，作者让 Claude Code 额外生成一个网页，把代码库结构可视化并把所有技术用小白语言解释出来，效果非常清晰有趣。

这个方法也带来一个完整视角：如果你想从零基础开始 coding 一款产品，需要哪些 SaaS 工具、花多少钱、这些东西是怎么连起来的。

## 一、产品代码库的分层架构

Claude Code 把整个代码库整理为一个分层的架构：

-   **界面层**：用户能看到的所有东西——画布、摄像头、气泡等。
-   **逻辑层**：各种 Hooks，负责串联交互。
-   **服务层**：真正干活的引擎，如视频录制、格式转换等。
-   **底层中枢**：App 文件，相当于一个中央指挥部，统一调度各服务。

## 二、用「群聊对话」可视化服务间通信

作者最喜欢、也最巧妙的部分：让 Claude Code 把各个服务之间的请求和连接用「群聊」的方式呈现，把抽象的服务调用翻译成角色对话，极大降低了理解门槛。

整个录制流程被演绎成这样的对话：

-   **用户**：进入软件，按下录制键。
-   **App 文件（导演）**：对所有服务喊话——「各位就位，开拍！」然后分别请求 Excalidraw 提供白板画面、请求摄像头提供人脸画面，把所有素材叠在一起，每秒叠 30 次，从而形成流畅的视频。
-   **Excalidraw（开源白板工具）**：依次报数——「这是第一张截图、第二张、第三张……」，每秒交出 30 张截图。
-   **App 文件**：把截图交给「压缩工」**WebCodecs**（浏览器内置的视频压缩工具）。如果浏览器版本太老，则让替补 MediaRecorder 上场。
-   **用户**：按下停止键。
-   **App 文件**：宣布「杀青，现在打包」——把所有内容编排成一个 MP4 文件下载到本地。
-   **PostHog（数据分析）**：在角落默默记账——「全记上了，别管我」。

用这种群聊式的比喻，服务之间的关系「怎么连起来的」就变得浅显易懂，甚至非常有趣。

## 三、做一款简单 Web App 需要的 SaaS 工具

作者梳理了产品用到的 7 个 SaaS 服务：

-   **Vercel**：网页部署与托管，使用付费版。
-   **Supabase**：数据库，用户账号体系的数据存在这里。
-   **Stripe**：收款工具，按手续费模式收费，无需提前预付订阅费。
-   **Namecheap**：购买域名，作者买了 excalidrawrecord 相关域名，约 11 美元（冷门词很便宜，热门词贵很多）。
-   **PostHog**：数据分析，了解有多少人用了产品、使用时长等；基础版基本免费，无需付费版。
-   **Google Login**：账号登录体系，完全免费。
-   **Claude Code**：负责编写整个 App，作者使用的是付费版本。

## 四、上线一款产品最低需要多少钱

主要开支集中在两个地方：

-   **Coding Agent**：Claude Code 的 Pro 版 20 美元/月，但对作者而言远远不够用，所以升级到了更高档位。市面上也有其他更便宜的 AI 编程产品可选。
-   **域名**：视域名热度从几美元到几十美元不等，作者这次只花了 11 美元。

其他服务（Vercel、Supabase 等）在正式商用前可以先用免费额度，几美元/月即可。商用后再视规模升级即可。

## 五、如何让 Claude Code 把代码库做成可视化拆解

作者给 Claude Code 的提示（Prompt）大致如下，可以直接复用：

> 把我的代码库做成一个交互式的可视化网页，面向没有编程经验的人。用聊天对话来比喻各个服务之间是怎么通信的，以及我的各个 SaaS 工具之间的真正关联（免费/付费等），所有的术语都要用大白话解释。

执行上有两种推荐形式：

-   让 Claude Code 输出为 Markdown 文档，便于沉淀。
-   （作者更偏好）让 Claude Code 输出为好看的前端页面，可读性更强、更美观、更容易理解。

## 全文整理

建议大家不仅要把 coding agent 当成你的工程师，也要把它当成你的老师。它能帮助你解释代码库，帮你变得更 technical。比如这是我最近发布的一个录屏产品 Excalidraw Recorder，这个产品我全程都是用 Claude Code 做出来的。那么我在做出来之后，还会让 Claude Code 去做一个网页，帮我把这个代码库的结构可视化，并且把所有的技术都用小白语言解释出来。我觉得它做的这个非常好，也非常有意思。我今天带大家过一下这个结构，以及如果你自己想从零、没有任何基础的情况下 vibe coding 一个产品，需要用到哪些 SaaS 的工具，以及多少钱，以及这些东西是怎么连起来的。

首先，它把我的整个代码库做了一个分层的架构。第一层是界面层，就是用户看到的东西，包括这个画布、摄像头、气泡等等。第二层是逻辑层，就是各种 hooks。然后在底层是服务层，就是干活的一些引擎，比如视频录制、转换等等。最底层是这个 app 的文件，它就是一个中央指挥部。

然后我最喜欢的是这个部分：服务之间怎么对话。因为这个是我在 prompt 里特意让 Claude Code 把各种服务之间的这种请求和连接，用一个群聊的方式说人话，帮助我去理解。比如说你是这个用户，当你来到这个软件按下录制键的时候，应用的那个文件就是说"各位就位，开拍"，然后他会跟 Excalidraw 说"把白板画面给我"，然后跟摄像头说"把脸给我"，然后他会把所有东西叠在一起，每秒叠三十次，这样看起来就是流畅的视频。

然后 Excalidraw 这个开源的白板工具就会说"这是第一张截图、第二张、第三张……"，然后它每秒钟交三十张截图。然后应用这个文件说"接下来我把这些文件交给压缩工"，这个压缩工叫 WebCodecs，它专门用来压缩的，是浏览器内置的。如果这个浏览器太老的话，它会让替补 FFmpeg.wasm 来干这个事儿。然后当用户按停止的时候，应用说"杀青，现在要打包"，打包就是把这些内容编排到一个 MP4 文件里，把它下载下去。

然后我用的数据分析的这个产品叫 PostHog，他就负责在角落里默默地往小本本上记，然后他还说"全记上了，别管我"。

我觉得用这种方式是真的能帮我非常容易地理解这些服务之间的关系是什么，它们是怎么连起来的，非常的浅显易懂，甚至非常的有趣。

### 做一个简单的 web app 需要用到哪些 SaaS

然后最后给大家看一下，做一个这样的简单的 web app 背后需要用到哪些 SaaS，然后大概需要多少钱。

这是我用到的七个 SaaS 的服务。Vercel 是用来做网页的部署和托管的，我用的是 Vercel 的付费版。然后 Supabase 是一个数据库，如果你有一个用户账号的体系的话，一般用户账号的信息就会存在这里。然后 Stripe 是用来收款的，它是收手续费的，所以你不用提前给它付订阅费。然后 Namecheap 是我用来买域名的，我买了 excalidraw.io 这个域名大概花了十一刀，这个属于非常便宜的。如果你要买一个非常火的那种词儿，它的域名会贵很多。PostHog 是我用来做数据分析的，就是要知道有多少人用了你的产品，用了多久等等，这个基本上就全是免费的，用不到付费版。然后 Google 登录是用来做账号体系的，它也是完全免费的。

最后我整个 app 是用 Claude Code 来帮我写的，然后我是在用 Claude Code 的付费的版本。所以说如果你是想要 ship 一个面向用户的产品，你最低需要花多少钱呢？主要的费用是你需要一个 coding agent，Claude Code 的 Pro 是二十刀，但是对我来说这是完全不够用的，所以我升级到了更高的档位。但是市面上有很多其他的 AI 编程的产品可以去选，很多是更便宜的。另外你买一个域名的话可能需要一笔钱，但是根据你的域名的不同它的价格也不同，我这个只花了十一块钱。然后你正式商用之后，你可以再把 Vercel 和 Supabase 升级一下。所以如果你没有商用的话，大概就是每个月几十刀。

### 怎么让 Claude Code 把代码库做成可视化拆解

那怎么让 Claude Code 来把你的代码库做成这样的拆解呢？我基本就是跟他说：把我的代码库做成一个交互式的可视化网页，面向没有编程经验的人，用后群聊对话来比喻各服务之间怎么通信，以及我的各个 SaaS 的工具，它们之间真实的关联，免费白嫖等等，写出来，以及所有的术语都要用大白话解释就可以了。

我是非常推荐大家把 AI coding 工具变成你的编程老师，因为它非常擅长把这些技术的概念翻译成小白易懂的语言。你可以让它写成 Markdown 的文档，但是我更 prefer 让它做成一个好看的前端的页面，这样我看起来更美观，也更容易理解。
