Google 开源了名为 **Modern Web Guidance** 的前端开发指导项目。上线仅 48 小时，它便登上 GitHub 热门榜第一。

## 为什么 AI 生成的前端代码容易过时？

目前，许多 AI 编写前端代码时，默认参考的知识仍停留在 2019 年左右。其训练数据大量来自 GitHub 上较早期的代码，模型往往会模仿这些旧代码的写法，导致生成结果难以体现现代 Web 开发实践。

换句话说，问题不一定是模型本身不够聪明，更可能是它使用的“教材”已经过时：看到什么旧代码，就容易按照什么方式编写。

## Modern Web Guidance 的作用

Modern Web Guidance 提供了一套面向现代 Web 开发的新教材和编码指导。AI 在生成代码时，可以参考其中的最新规范，以改善前端代码的写法与质量。

## 显著的效果提升

借助这套新的开发指导，相关前端能力指标从 **56%** 提升至 **88%**。

这项提升说明，更新 AI 所依赖的知识来源，可能比单纯追求更大的模型规模更直接地影响代码生成质量。关键并不在于让 AI “变得更聪明”，而在于为它提供更现代、更准确的参考资料。

## 全文整理

谷歌开源了 Modern Web Guidance，48 小时直接登上 GitHub 热门榜第一。此前，AI 写前端时，默认采用的往往还是 2019 年的技术方案。

原因很简单：AI 的训练数据里全是过时的老代码和“老屎山”。它学习编程时，主要依赖从 GitHub 上抓取的旧代码；旧代码是什么样子，它就会按照什么样子来写。

谷歌开源的 Modern Web Guidance，相当于为 AI 编写了一套新的教材。AI 在写代码时，可以随时查阅这套指南，按照新的写法完成前端开发。这样一来，AI 编写前端代码的能力从 56% 提升到了 88%。

这并不是 AI 变聪明了，而是给它换了一套更新的教材。这个思路，确实很巧妙。
