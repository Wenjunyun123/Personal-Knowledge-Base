开源项目 **OpenFilm** 提供了一种基于网页技术制作视频的新思路：使用 HTML 和 CSS 编写画面，将每个视频镜头视作一个独立网页。

## 用 AI 创建视频素材

OpenFilm 可以让 AI 直接生成画面、动画和转场，再将这些元素组合为完整视频，让网页技术也能用于视频内容创作。

## 生成后继续精细调整

视频生成后仍可进入编辑阶段，像使用剪映一样拖动时间轴、修改文字并调整镜头，对最终效果进行微调。

## 导出与使用

-   编辑完成后可直接导出 MP4 视频。
-   项目完全开源且免费，适合个人体验和探索新的视频制作方式。
