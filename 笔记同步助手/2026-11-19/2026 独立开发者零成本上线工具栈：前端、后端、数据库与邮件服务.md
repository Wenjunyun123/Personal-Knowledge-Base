独立产品从 0 到 1 上线，通常需要准备前端托管、后端服务、数据库、对象存储、身份认证和邮件发送等基础设施。本文整理了一套适合个人开发者的低成本工具组合，帮助开发者降低前期试作成本。

## 一、前端托管

### Cloudflare Pages

Cloudflare Pages 可以直接构建并托管前端项目，生成二级域名，部署后即可访问。它不限制带宽，并且支持商业用途，适合作为独立产品的免费前端托管方案。

### Vercel

Vercel 同样支持将前端项目直接构建到平台，并提供可访问的二级域名。不过，免费方案更适合个人博客、作品集等非盈利项目；如果需要商业使用，则需要升级到 Pro。

## 二、后端部署

### Supabase

Supabase 是一套开箱即用的后端服务，可以直接提供项目所需的后端能力。它不限制 API 请求数量，但有每月 5 GB 的出站流量限制。

如果产品流量已经达到这个量级，说明产品可能已经具备一定市场需求，此时可以开始考虑投入更多成本。

### Cloudflare Workers

![[笔记同步助手/images/d2eae60ee89b3204e8746c4dfb172b0b_MD5.jpg|前端托管工具 Cloudflare Pages 与 Vercel 的方案对比及使用限制。]]

## 三、数据库

### Supabase

Supabase 提供 PostgreSQL 关系型数据库。每个项目的数据容量限制为 500 MB，对于个人项目的前期开发阶段通常已经足够。

### Cloudflare D1

Cloudflare D1 支持最多 10 个数据库，总存储空间为 5 GB。每天提供 500 万行读取和 10 万行写入额度。

## 四、文件与对象存储

### Supabase Storage

Supabase 提供 1 GB 免费存储空间，单个文件大小上限为 50 MB，适合保存少量图片、附件或项目文件。

### Cloudflare R2

Cloudflare R2 提供 10 GB 存储空间。作为项目初期的文件存储方案，容量通常已经十分充足。

## 五、身份认证

### Supabase Auth 与 Clerk

独立产品的登录、注册和用户身份管理，可以选择 Supabase Auth 或 Clerk。两者都提供 5 万月活用户额度，足以覆盖独立开发者前期阶段的需求。

邮件服务可以使用 Resend。免费方案每天支持 100 封邮件，配置相对简单，但需要拥有自己的域名。

### 前端托管

前端托管主要可以选择 Cloudflare Pages 和 Vercel。

这两个工具都可以直接将前端项目构建到对应平台，并提供二级域名，部署完成后即可访问。

二者的区别在于，Cloudflare Pages 不限制带宽，并且可以用于商业项目；Vercel 更适合非盈利项目的部署，比如个人博客、作品集等，因为其官方明确说明，商业使用需要升级到 Pro 套餐。

Cloudflare 非常慷慨，使用时也不需要再手动一步步操作。只需要告诉你的 AI Agent：“将我的项目部署到某个工具上。”AI 就会帮你完成后续工作。下面要介绍的工具同样可以使用这种方式部署。

### 后端部署

后端可以使用 Cloudflare Workers，或者直接使用 Supabase 这种开箱即用的后端服务。

Supabase 在此前的视频中已经单独介绍过。它不限制 API 请求数量，但有 5GB 的出站流量限制。不过，如果项目真的达到这个流量规模，也说明产品已经有了市场，可以开始投入一些成本。

Cloudflare Workers 每天提供 10 万次免费请求，并且没有带宽限制，非常慷慨。

### 数据库

数据库可以选择 Cloudflare D1、Supabase 和 Turso。

Supabase 提供 PostgreSQL 关系型数据库，每个项目的数据容量限制为 500MB，前期使用肯定足够。

Cloudflare D1 支持 10 个数据库，总存储空间为 5GB，但每天有 500 万行读取和 10 万行写入的限制。

另一个选择是 Turso。它支持 100 个数据库，总存储空间同样为 5GB，并按月更新读写额度：每月可以读取 5 亿行，写入 1000 万行。

### 存储

文件存储可以继续使用前面提到的老朋友：Cloudflare R2 和 Supabase。

Supabase 提供 1GB 的免费存储空间，单个文件上限为 50MB。

Cloudflare R2 提供 10GB 的存储空间，作为项目初期的存储已经绰绰有余。

### 二次认证

二次认证可以选择 Supabase 或 Clerk。

Supabase 提供 5 万月活用户，Clerk 同样提供 5 万用户额度，足以满足独立开发者前期使用。

### 邮件服务

邮件服务可以使用 Resend。

Resend 每天支持发送 100 封邮件，使用比较简单，但需要拥有自己的域名。另外，国内一些互联网大厂也提供相应的免费邮件额度。

以上就是独立开发者在产品发展前期几乎会用到的全部上线工具。互联网上确实还有大量这样的用户存在。
