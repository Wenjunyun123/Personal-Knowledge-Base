## 项目核心：把人物思维整理成 Skill

这个 GitHub 开源项目将行业人物的特征集中整理并“蒸馏”为可调用的 Skill，包括人物特有的表达方式、思维模式、价值观以及商业决策启发等内容。

项目汇集了不同人物对应的 Skill，并且全部开源。使用者只需选择目标人物，将其 Skill 复制到 OpenClaw 或扣子（Coze）中，待工具自动安装完成后即可使用。

![[笔记同步助手/images/4ebb34ec40049f341e9f87e1b17ce9d0_MD5.jpg|GitHub 开源人物 Skill 项目及安装使用界面]]

GitHub 开源人物 Skill 项目及安装使用界面

## 使用方式

1.  在项目中选择需要参考的人物。
2.  复制该人物的 Skill，并安装到 OpenClaw 或扣子（Coze）。
3.  围绕产品策略、项目分析、职业规划等问题与该 Skill 对话，获得基于人物认知视角的回答。

## 实际体验：乔布斯 Skill

视频以乔布斯的 Skill 为例，让其分析个人项目框架。生成的建议较为细致，不仅给出具体分析，也能在表达方式和思考路径上明显体现乔布斯的认知特征。

## 项目特点

-   **人物思维结构化：**将表达、思维模式、价值观和决策启发整理为可复用资源。
-   **安装门槛较低：**复制对应 Skill 到常用智能体工具即可使用。
-   **覆盖多种场景：**可用于产品策略、项目分析和职业规划建议等任务。
-   **全部开源：**每个人物的 Skill 都可直接获取与使用。

## 全文整理

这些行业大佬的表达方式、思维模式、价值观，以及商业边界和决策启发式，被完整蒸馏出来，制成了 Skill。而这个项目本身就叫 Skill。

使用方式非常简单：只需要将对应人物的 Skill 复制到你的 Claude 或 Coze 中，等待它自动安装完成。接下来，无论是制定产品策略、进行分析，还是获取职业规划建议，都可以直接与对应人物对话，寻找答案。

例如，我测试了乔布斯的 Skill，让它帮我分析项目框架。它给出的建议非常细致，而且从思路和表达方式上，都能明显感受到乔布斯式的认知。

这个项目非常强大，而且每个人物的 Skill 都直接开源。
