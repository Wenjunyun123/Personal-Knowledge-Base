# 增量入库

## 给 Codex 的日常请求

```text
请把以下资料增量入库到“笔记同步助手”个人知识库：
<在这里粘贴一到数个文件路径>

先完整读取 笔记同步助手/AGENTS.md。不要修改、移动或重命名 Raw 原文。
处理前用 id、URL、标题、别名和关键词搜索现有 wiki，先查重，再决定补充旧页还是新建页。
为每份资料维护来源摘要，只提取有复用价值的概念、实体和主题；事实就近链接来源，推断与待核实内容分开写。
最后更新 index.md，在 log.md 末尾追加记录，运行 scripts/Validate-KnowledgeBase.ps1，并汇报实际新建/更新文件、Raw 哈希和校验结果。
```

## 人工验收

- 来源摘要是否能返回原文。
- 是否把作者观点误写成独立确认事实。
- 是否产生同义重复页或无复用价值的实体页。
- 是否保留了冲突、时效性和待核实项。
- Raw 哈希是否保持不变。
