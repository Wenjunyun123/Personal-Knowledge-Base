最近发现一个挺有意思的 GitHub 开源项目，叫 Financial\_freedom（财富自由）  
  
作者把投资学习资料做了系统化梳理，上手门槛低，直接就能用，  
  
核心内容包括：  
  
经典阅读：16 本从入门到精通的投资必读书单  
视听精选：16 部顶级财经纪录片 + 23 个优质美股 YouTube 频道  
社群与工具：精选美股讨论社区，以及实用性强的 Web3 / 区块链工具站  
  
虽然名字叫「财富自由」听起来口气不小，但内容确实扎实，非常适合想在熊市里系统搭建投资框架、补齐认知短板的朋友  
  
项目地址：[github.com/codeman008/Financial\_freed…](https://github.com/codeman008/Financial_freedom)
