# Anthropic 放出官方手把手教程，直接由 Claude 的首席工程师亲自下场，37 分钟搞定 7×24 值守智能体，博主称干货胜过 1500 刀付费课。

## Anthropic 官方教程：37 分钟搭建 7×24 值守的生产级 AI Agent

Anthropic 刚刚发布了一份 37 分钟的免费课程，由 Claude 团队的首席工程师亲自授课，课程名称是《Ship your first Managed Agent》。

教程手把手带你搭建一个 7×24 小时值守的生产级 AI 智能体，依托云端托管能力，无需自己维护 Agent 循环。只需使用 6 个函数，就能实现：

-   自定义工具
-   子智能体
-   内存管理
-   凭据库
-   业务流程自动化

这份教程的内容含金量被博主评价为对标市面上 1500 美元的付费课程。想做 AI Agent 的开发者可以完整看一遍。

### 边看边改成自己的业务版本

如果担心“收藏了吃灰”，可以边看教程边开着 ChatGPT。每暂停一段，就让它把这段内容换成自己业务的版本。

这样 37 分钟看完，手里就会有一份属于自己的 Agent 草案，而不是又多了一个收藏。

### 搭建前先理清业务流程

业务流程都没理顺就直接上 Agent，等于把一团乱麻跑得更快。

37 分钟能讲清楚怎么搭 Agent，但讲不明白你家里那堆没人说得清的流程到底应该长什么样。对于小白来说，还是应该先把自己的流程图画明白，再开始搭建。

看不明白的地方可以多看几遍、多实践一下。

### 先明确权限、验收与故障排查

对于 7×24 小时运行的 Agent，最怕的不是搭不起来，而是半夜跑偏了却没人拦截。因此，应该先明确：

-   权限边界
-   验收规则
-   执行逻辑

可以先拿故障排查来练手，让 Agent 过一个试用期，之后再考虑自动化整个业务。
