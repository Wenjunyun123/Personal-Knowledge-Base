# 分类 Raw 使用说明

`raw/` 用于以后手工导入、且不由“笔记同步助手”日期目录管理的资料。

- [[笔记同步助手/raw/articles/_README|articles]]：文章与网页剪藏
- [[笔记同步助手/raw/papers/_README|papers]]：论文与报告
- [[笔记同步助手/raw/books/_README|books]]：书籍、划线与读书笔记
- [[笔记同步助手/raw/chats/_README|chats]]：有长期价值的 AI 对话
- [[笔记同步助手/raw/notes/_README|notes]]：灵感与随手记录
- [[笔记同步助手/raw/meetings/_README|meetings]]：会议纪要与转写

根目录下已有的 `YYYY-MM-DD/` 和 `images/` 同样属于 Raw，不需要复制到这里。资料一旦进入任一 Raw 区域，即按只读证据处理。
