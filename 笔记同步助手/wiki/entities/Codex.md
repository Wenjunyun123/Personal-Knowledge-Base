# Codex

## 是什么

在本知识库流程中，Codex 是读取本地资料、按 `AGENTS.md` 执行检索与文件维护、并输出验证证据的 Agent 执行层。这个定义描述的是当前项目用法，不是完整产品说明。

## 在本知识库中的角色

- 读取指定 Raw，但不修改原文。
- 检索现有 Wiki，创建或合并来源、概念、实体和主题页。
- 维护双链、索引、只追加日志和待确认列表。
- 运行只读校验并汇报实际文件结果。

这些职责来自指定来源的方法，并由当前项目的 [[笔记同步助手/AGENTS]] 进一步收紧。[[笔记同步助手/wiki/sources/用 Codex + Obsidian 搭建自生长的个人知识库实战]]
