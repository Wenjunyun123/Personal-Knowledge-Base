🧠 又发现一个能让 AI 真读懂你整个资料库的开源项目。  
  
GitHub 揽获 3.8 万 star，背后是香港大学的正经论文。  
  
普通做法是把文档切块塞进向量库，AI 经常只找到零碎片段、答非所问。LightRAG 在向量之外还建了一张知识图谱，把资料里的实体和关系连起来，问它一个问题，能顺着关系把相关信息一起捞出来，答得更准更全。给了 WebUI、REST API 和 Python SDK，本地搭一套私有知识问答不算折腾。  
  
想让 AI 当你私人研究员的，这个值得收藏。  
  
GitHub：[github.com/hkuds/lightrag](https://github.com/hkuds/lightrag)
