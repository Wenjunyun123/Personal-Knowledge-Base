## 项目概览

Page-Agent 是阿里开源的一个网页智能体项目，已在 GitHub 获得 18.7K Star。它的核心能力是把 AI Agent 直接嵌入网页，让用户可以通过自然语言控制网页界面。

![[笔记同步助手/images/68eaf1f7bf2e979b40514e27a82ff17f_MD5.jpg|Page-Agent 项目介绍画面]]

Page-Agent 项目介绍画面

## 核心能力

接入 Page-Agent 后，用户可以用自然语言指挥网页完成常见交互操作，例如点击按钮、填写表单、推进页面流程等。

-   支持用自然语言控制网页界面。
-   可执行点击、填表、流程跳转等操作。
-   适合作为网站中的 AI 副驾驶使用。

## 技术特点

Page-Agent 的特点在于它不依赖传统的自动化浏览器方案，也不需要复杂的视觉识别链路。

-   不需要 headless 浏览器。
-   不需要截图。
-   不需要 OCR。
-   不需要多模态模型。

## 接入方式

项目强调轻量接入：通过一行 script 标签，就可以让网站具备一个可用自然语言操控的 AI 副驾驶。
