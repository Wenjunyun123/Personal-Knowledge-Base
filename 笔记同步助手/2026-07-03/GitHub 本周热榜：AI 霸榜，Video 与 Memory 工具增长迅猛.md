## GitHub 本周热榜：AI 霸榜，Video 与 Memory 工具增长迅猛

本周 GitHub 热榜上，开发者们关注的多个项目均与 AI 相关，尤其在视频生成和长期记忆领域表现突出。以下逐一介绍。

### 1\. Open Montage — 视频自动制作工作室

将 AI 编程助手转变为视频制作工作室。只需一句话描述需求，即可自动完成从策划到渲染的全流程。项目一周获得 18K 星，总数 25.6K 星。拥有 12 条生产流水线、52 个工具、500 多个 Agent 技能，支持真实素材剪辑，不仅仅是生成图片动画。被认为是目前最完整的开源视频生成系统。

![[笔记同步助手/images/d25a93b08a1ec34f9fc6372e527eb3a1_MD5.jpg|Open Montage 演示界面]]

Open Montage 演示界面

### 2\. Agent Rich — 免 API 的联网 Agent

让 AI Agent 能够读取 Twitter、Reddit、YouTube、小红书以及 GitHub 等平台的内容，完全免费，无需 API Key。安装后只需一句话，Agent 自动完成配置和调用，无需手动折腾。若平台被封，自动切换备用方案。本周新增 7.7K 星，总数 43.7K 星。

### 3\. Codebase Memory MCP — 代码库智能索引

一个代码智能 MCP 服务器，可将代码库索引为知识图谱，实现毫秒级查询。支持 158 种语言，Token 消耗降低 99%。采用 Linears 内核，2800 万行代码可在 3 分钟内索引完毕，查询响应不到 1 毫秒。本周新增 7.7K 星，总数 18K 星。单文件安装，零依赖，兼容 11 种主流编程助手。

### 4\. Daily\_Stock\_Analysis — LLM 驱动的多市场股票分析

基于 LLM 的多市场股票分析系统，支持 A 股、港股、美股、日股、韩股，聚合行情、新闻和技术指标，自动生成买卖决策看板，并推送到企业微信、飞书或 Telegram。借助 GitHub Actions 可零成本定时运行。本周新增 7.1K 星，总数 50.6K 星。

### 5\. Cogni — 长期记忆平台

为 AI Agent 提供长期记忆的开源平台，让 Agent 跨会话记住重要信息。支持数据导入、知识图谱构建和语义检索，端到端开源，支持 PostgreSQL 作为统一后端。在 BEAM 基准测试中，以 100K token 上下文场景得分 0.79，打败了之前的 SOTA。本周新增 5.5K 星，总数 24K 星。

![[笔记同步助手/images/80490cff9b41dbf995367a6ecf380da8_MD5.jpg|Cogni 长期记忆平台架构]]

Cogni 长期记忆平台架构

### 6\. Antropic Cybersecurity Skills — 网络安全技能库

包含 817 个网络安全技能，映射到 MITRE ATT&CK、NDCK、NST、CSF、ATLAS、AND、NIS、TAIMF 以及新出的 F3 反击框架。覆盖 29 个安全领域，6 大框架全部映射。为 AI Agent 提供安全专家级别的操作手册，涵盖渗透测试、威胁狩猎、DFIR 等领域。本周新增 5.1K 星，总数 2.3K 星。

### 7\. AI Website Cloner Template — 一键克隆网站

一行命令即可克隆网站。AI 自动分析目标站点，提取设计规范，并行构建每个区块，最后合并成干净的 Next.js 代码。技术栈为 TypeScript + Next.js + Tailwind CSS。总星数 23K，本周新增 4.6K 星。

### 8\. Voicebox — 开源 AI 语音工作室

开源 AI 语音工作室，集成 7 种 TTS 引擎，支持 23 种语言，零样本声音克隆和全局听写。可为 AI Agent 装上声音。基于 Tori + Rust 构建，本地运行无需联网，保障隐私安全。支持 Queen3 TTS、Chatterbox、Cocoro 等引擎，并带有 Pitch、Reverb、Delay 等效果。本周新增 4K 星，总数 35K 星。

### 9\. Penpot — 开源设计工具

对标 Figma 的开源设计工具，支持 SVG、CSS、HTML 设计，实时协作，设计令牌，以及 MCP 服务器，打通设计到代码。用 Closure 编写，可在浏览器直接运行或自托管。设计师和开发者可用它无缝交接，设计稿直接导出可用代码。本周新增 3.3K 星，总数 54.2K 星。

### 10\. Deerflow — 字节开源 Super Agent 框架

字节跳动开源的 Super Agent 框架（重写版），由 LangGraph 驱动，支持子 Agent、沙箱执行、长期记忆和 IM 渠道接入（Telegram、飞书、微信）。可将复杂任务分解给子 Agent 并行执行，实现分钟到小时级任务的全自动处理。本周新增 3.3K 星，总数 75.1K 星，热榜中最高。
