Remotion + Three.js 复刻的苹果产品发布会风格动画效果

## 实现思路概览

整体采用 React + Remotion 控制时间轴与动画节奏，使用 Three.js / React Three Fiber 加载真实的 3D 产品模型，核心目标是让动画节奏贴合原视频音乐。

## 关键实现步骤

### 1\. 时间轴与动画框架

使用 React + Remotion 搭建整体时间轴，统一管理动画节奏。

### 2\. 三维模型加载

通过 Three.js / React Three Fiber 加载提供的 5 个 GLB 产品模型，实现真正的三维旋转，而非用图片模拟。

### 3\. 字母与产品对应

Apple 的五个字母分别对应一款产品：

-   **A** — Mac Studio
-   **p** — iPhone
-   **p** — MacBook（此处按作者描述对应 Apple 字母位排列）
-   **l** — Vision Pro
-   **e** — AirPods

展开阶段，模型从各自字母所在位置同步淡入、放大，并向两侧散开。

### 4\. 独立三轴旋转轨迹

每个产品采用独立的三轴旋转轨迹，以呈现不同展示重点：

-   **Mac Studio**：展示机身侧面与接口细节
-   **iPhone**：展示正面与边框
-   **MacBook**：增加俯仰角，强调开合与形态
-   **Vision Pro**：以正面为主，仅做小幅摆动
-   **AirPods**：展示耳机盒的空间深度

### 5\. 收束与字标恢复

模型在动画末尾分别回到对应字母位置，在原位缩小并淡出，随后恢复完整的 Apple 字标。该步骤需要避免模型集中堆叠或与文字重叠。

### 6\. 模型预加载

所有 GLB 在动画开始前统一预加载，确保模型全部就绪后才开始播放，避免产品不同步、模型突然出现的跳变问题。

### 7\. 音频对齐

原视频音频作为时间基准嵌入，关键的展开、停留与收缩节点按音乐节奏对齐，使动画与音频同步。

## 小结

整个流程的核心在于：**Remotion 控节奏、Three.js 出三维、预加载保稳定、音频驱动节点对齐**。四者配合即可在 Web 端复刻出接近官方产品发布会的视觉质感。

## 全文整理

在 Timeline 上刷到 Bruno Henrique 制作的动画，灵感随之而来：能否用 Remotion 复刻这一作品？经过尝试，答案是肯定的。

以下是实现过程：

### 技术栈与时间轴控制

整个项目基于 React 与 Remotion 构建。Remotion 负责控制视频的时间轴与动画节奏，使每一帧的推进都具备精确的可编程性，而不是依赖预渲染视频的拼接。

### 三维模型加载

选用 Three.js 与 React Three Fiber 来加载提供的五个 GLB 产品模型。与用图片序列模拟三维旋转不同，这种方式可以实现真正的实时光栅化三维渲染，模型在任意角度都能保持正确的透视与光照表现。

### 字母与产品的对应关系

五个 Apple 字母分别对应一件产品。展开阶段，模型从各自字母所在的位置同步淡入、放大，并向左右两侧散开，形成由文字向立体产品的视觉过渡。

### 每个产品的独立旋转轨迹

为了让每件产品都能展示最具辨识度的角度，我为它们分别设计了三轴旋转轨迹：

-   Mac Studio 重点展示机身侧面与接口排列，强化其作为桌面工作站的专业感。
-   iPhone 着重呈现正面屏幕与边框的精致工艺。
-   MacBook 在旋转过程中加入俯仰角，模拟开合与倾斜的自然姿态。
-   Vision Pro 以正面为主视角，只做小幅度的轻微摆动，避免画面过于跳跃。
-   AirPods 通过旋转突出耳机盒的空间深度，呈现其紧凑而精致的造型。

### 回收与字标复原

动画收尾阶段，五个模型分别回到各自对应的字母位置，在原位逐渐缩小并淡出，随后恢复完整的 Apple 字标。为避免模型集中堆叠或与文字发生重叠，回收路径与初始展开路径严格对称，并预留了足够的安全间距。

### 预加载与同步问题处理

所有 GLB 模型在动画正式开始之前统一进行预加载。只有当五个模型全部加载就绪后，时间轴才会启动播放。这一处理解决了不同产品因加载速度不一致而出现的"突然出现"或节奏错乱的问题。

### 音频与节奏对齐

原视频的音频作为时间基准被嵌入项目中，关键的展开节点、停留节点与收缩节点都按音乐节奏进行对齐，使视觉变化与听觉感受形成统一的节拍。
