一套 AI 短剧制作的完整 skill 集合：shuohao-skills。把一本小说改编成可直接投产的制作素材，在 Claude Code 和 codex 上运行。  
  
GitHub：[github.com/eternityspring/shuohao-ski…](https://github.com/eternityspring/shuohao-skills)  
  
在线体验：[reelbench.79px.com](https://reelbench.79px.com)  
  
完整管线五步走：  
  
novel-outline：把小说改编成短剧大纲五件套（改编说明、人物表、爽点表、分集梗概、资产清单），14 道质量门脚本检查，支持体检模式。  
  
novel-characters：生成角色设定集（人物画像、形象提示词、音色提示词、角色设定图），读取大纲预填角色表。  
  
novel-art：生成美术设定集（场景 + 叙事道具），提供一致性锚点、光照与状态变体、尺度参照，11 道质量门检查。  
  
novel-script：写剧本（场次 + 节拍流），逐集时长按语速确定性折算，台词本按角色聚合带音色提示词直接对接 TTS，10 道质量门检查。  
  
novel-storyboard：输出分镜（段 → 分镜 → 分镜图），MiniMax H3 提示词逐字对账，分镜图用设定图做参考，一键导出投产包，17 道质量门检查。  
  
每个 skill 自包含、可单独运行，零 npm 依赖。所有报告支持中英双语界面，可合成单页导航切换。
