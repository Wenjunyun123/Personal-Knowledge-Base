刷 GitHub 看到个开源项目：ai-website-cloner-template  
  
简单来说，你扔给它任何一个网站的链接，AI 就能直接把人家的前端网页完整复刻出来。  
  
平时看到竞争对手家做的精美落地页，或者大厂很炫酷的页面布局，以前还要苦哈哈地审查元素去抄，现在直接一键让 AI 把它的骨架和样式扒下来研究，简直是偷师神器。  
  
重点是生成的代码极其干净，没有垃圾代码，直接就能用。  
  
做产品或经常需要搞网页的朋友闭眼收藏就完事了。
