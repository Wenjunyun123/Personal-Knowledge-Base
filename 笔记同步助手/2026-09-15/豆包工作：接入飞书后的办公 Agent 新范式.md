## 一、核心变化：豆包工作 × 飞书，Agent 进入你的工作现场

豆包工作（豆包团队近期推出的办公专用 Agent）与飞书深度结合后，界面和功能均已升级。除了常见的技能调用、外部应用连接、定时任务、操控本地电脑外，它还配备云电脑并支持手机遥控。但最关键的差异在于：用飞书登录后，上下文彻底打通了。

所谓上下文，就是做一件事所需的全部来龙去脉。普通 Agent 不会主动组织上下文，用户每次都要重复大量前提，效果往往不尽人意。而豆包工作接入飞书后，能直接进入你的工作现场，自动梳理：

-   文档、表格、群聊、会议纪要、日历
-   组织关系（部门、岗位、负责人）
-   请假、审批等流程进度

它就像一位与你同一天入职的老同事，共用同一台电脑，所有上下文完全拉通。结果是：同样的任务，它干得更省心、效果更好，因为和你有默契。

## 二、典型应用场景

### 案例 1：HR 询问招聘进度

公司招聘期间简历投递量大，HR 直接问 Agent：「现在还有多少人笔试交了但没阅卷，给我汇总一下」。提示词几乎没有铺垫，几分钟后 Agent 就给出了可视化报告。

随后只需追加一句：「把他们的资料和笔试题按不同岗位打包，发给岗位负责人催他们评卷」。Agent 立即自动发送消息，并附带清晰的文档——连「负责人是谁」都不用你交代，因为部门人员信息在多维表格中一目了然。

过去给客户做方案需要写一大串提示词（要求、参考文件……）。现在可以直接说：「我要给客户做一个鸡尾酒品牌设计，要求在会议上说过，风格和报价跟之前小黎做的茶饮品牌很像，你参考那个给我出个方案。」

Agent 会自己去翻客户的会议纪要、去看同事过往项目，无需人工转述。它官方自带设计技能，并集成了 Seed 5.0 图像生成能力，直接输出成品方案。更重要的是，它的经验会边做边积累，多模态能力使日常办公方案的可用率大幅提升。

音频使用了新上线的 Seed Audio 音频模型，喊麦效果十足。该模型一句话即可用于做播客、讲故事、做相声。

## 三、更强项：跨月大项目与系统搭建

豆包工作可以和你持续协作长达数月的大项目，甚至帮你搭建完整系统。例如产品即将上线时，希望全公司参与测试并提 Bug，传统做法需要开发一系列应用：

-   引导不熟悉产品的同事进行测试
-   方便提交 Bug
-   Bug 自动记录到多维表格
-   同步至仓库 Issue
-   每日汇报 Bug 修复数量

只需用大白话把想法告诉 Agent，它当场完成开发、部署、发到群里。引导页面、提交页面、表格收集、每日提醒全部跑通。因为它连接本地电脑可直接看到代码、连接 GitHub 可直接提交 Issue，还能自动操作多维表格、开发应用并部署——几乎是团队里最了解全局的人，适合串联各环节搭建系统。

项目结束后还能靠它复盘，将流程沉淀为技能供整个团队共享。

## 四、第四层能力：远程遥控

新 Agent 能力丰富，包括 Seed Audio、Seedream、Seedance 等多种模型，以及大量 MCP 连接器。最关键的是：手机、电脑数据互通，并附带一台云电脑，等于随身带了一位 24 小时在线的同事。

典型场景：你在外面吃午饭，竞品突然上新爆款，老板让你赶紧分析。直接打开手机，选上云电脑，下达指令：

> 帮我做一个竞品分析，去全网找「飞书录音豆」的相关信息（官网、电商平台、社交媒体），重要信息都要截图，分析产品定位、竞争策略以及上线后的用户反馈和数据销量，最终做成交互式应用展示。

选上「应用生成产品分析报告」技能后锁屏，继续吃饭。Agent 在后台用云电脑浏览器自动点击、截图、翻页、收集信息、开发应用，并可能自主派出多个子 Agent 协作。吃完饭回工位，刚好验收成果——多页图文并茂，分析详尽，可直接转发给老板。

-   上下文自动组织，无需反复铺垫

## 全文整理

【说话人1】朋友们，刚发布的豆包工作太好用了。无论你用没用过市面上的办公 Agent，今天看完都会有收获，这个真的不一样。何况他现在还能免费领三十天的订阅，上班族们来吧，点好收藏、关注、赞，今天来打通你的任督二脉，刷新你对用豆包的认知。

### 豆包工作是什么

豆包工作是跟飞书结合之后刚刚发布的办公专用 Agent。界面大概就长这样：什么技能、连接外部应用、定时任务、操控本地电脑，市面上 Agent 有的它都有。额外的是，他还有一台云电脑，还能手机遥控。但是这些都不是重点，最关键的区别在于——用飞书登录之后，上下文自由了。

上下文说白了就是我们做一件事要知道的所有来龙去脉，就像新同事来了，你还得给人介绍一遍公司和项目的情况。但是很多朋友用普通的 Agent，它不会给 Agent 组织上下文，于是大多数人找 Agent 干活都像让临时工做事，每次都得说一大堆前提，效果还不尽人意。

豆包工作用飞书登录之后，等于是让 Agent 直接进入了你的工作现场。他会梳理你的文档、表格、群聊、会议纪要、日历、组织关系，包括你的请假审批进度，全都是豆包工作的上下文，他全都知道，还全都能操作。他就像一个跟你同一天入职的老同事，还跟你共用一台电脑，上下文完全是拉通的。结果就是同样的活他干得更省事儿，效果还更好，因为跟你非常有默契。

好，那我们一个个看具体案例，越往后越强。

### 工作的情况直接问他

首先，工作的情况问他比问任何人都靠谱。比如我们最近公司招人，投递简历的人很多，我们的 HR 就会直接问他：现在还有多少人笔试交了但没阅卷？给我汇总一下。

你看我这个提示词可以说是没头没尾，但是几秒他就给你出了一个可视化的报告。而且你还可以继续说：那把他们的资料和笔试题都按不同的岗位打包，发给岗位的负责人，催他们阅卷。当当，消息都直接发出去了，还给你配了清晰的文档。关键我都不用说负责人是谁。

究其背后的原因也很简单：我们的招聘人员表格就在多维表格里，我们的部门人员他也能看到。不过能查只是基础，有了上下文之后干活才是真爽。

### 帮客户做方案

比如说你要给客户做方案，你一般都得写一大串提示词吧？什么我要做一个什么方案，要求是巴拉巴拉，参考文件是巴拉巴拉。但是我可以直接跟他说：我要给客户做一个鸡尾酒品牌设计，要求呢都在会议上说了。我觉得范式和报价跟之前小黎做的茶饮品牌很像，你参考他那个给我出个方案。一整个借鸡下蛋有没有。客户的会议纪要他会自己去翻，同事的过往项目他会自己去看，我都不用给他转述。

然后他还官方自带了设计技能，还有强大的 CG 5.0 生图，直接就给我做成这样了。并且他的经验还在边做边积累，再加上它的多模态能力，日常的办公方案真的是可用率大幅提高，好看、信息又准确。

### 新人入职

那我说个有意思的：新人入职大家都要给他介绍公司什么情况吧，也要给大家介绍新人什么情况吧。因为豆包工作对公司和新人的情况两边都清楚，而且我们已经让他做过几次了，他就熟门熟路了。HR 只需要一句话：今天某某某入职，做个欢迎卡片和介绍公司的音频，发到群里。你看看，定制的新人介绍条漫，还有一条公司介绍音频。

【说话人2】你杨怀宇，新来的行政，站好了。你今天踏进秋之二零四六的大门，我告诉你，你算是来对地方了。

【说话人1】节目效果直接拉满。豆包工作多模态能力确实很强，这个喊麦就是用他新上的 Seed Audio 音频模型，一句话用它做播客、做故事、做相声都很给力。

所以说像我们这种一直用飞书的团队，让他干起活来就像一个入职多年的老同事，一干一个准。当然如果你公司不用飞书，你用个人飞书登录也可以，因为你跟豆包的协作也可以沉淀下来，他会越用越懂你。

### 跨几个月的大项目

OK，到这儿其实已经很强了，但它还能更强。他可以跟你持续一起干那种跨几个月的大项目，甚至帮你建系统。

比如说我们最近在开发产品，快要上线的时候，我想让全公司都参与测试来提 Bug。那我就想开发一个小应用，来指导那些不了解产品的同事也测试，然后方便他们提交 Bug。这些 Bug 还能自动记到多维表格里面，然后自动同步到 GitHub Issue，每天还能给我汇报修了多少 Bug。这听着是不是有一点复杂？是一个系统吧。

但是我就大白话地把我的想法跟他说了，他就当场开发、部署、发群里。这个是引导页面，这个是提交页面，表格收集、Bug 提交、每日提醒全部跑通。因为他连着我的本地电脑，他可以直接看到代码；他也连着 GitHub，可以直接提交 Issue；他还可以自动操作多维表格，他还能开发应用、部署妙搭。你会发现他几乎是团队里面最知道情况的人，所以他很适合串起这些环节来做系统。完了你还能靠他复盘，能沉淀成技能，整个团队共享。仙境实在是仙境。

### 远程遥控

那第四层就是远程遥控。而且他新的 Agent 的能力也很多，像刚才用到的 Seed Audio、SeeDream、SeeDance，还有一大堆 MCP 的连接器。最关键的是他的手机、电脑数据是互通的，还带一个云电脑给你，等于你随身带了一个二十四小时在线的同事。

假设你在外面吃午饭，竞品突然上新爆款，老板非常紧张，让你赶紧分析分析。你就可以直接打开手机，选上云电脑，然后说一句：帮我做一个竞品分析，去全网找这个飞书录音豆的相关信息，官网、电商平台、社交媒体，重要的信息都要给我截图。分析他们的产品定位、竞争策略，以及目前上线之后的用户反馈和数据销量，最终做成交互式的应用展示。然后你还可以点开这个技能，选上应用生成产品分析报告，然后锁屏，继续吃饭。

他就会在后台用云电脑的浏览器里面自己去点击、截图、翻页、收集信息、开发应用，而且还可能自主地派出一些不同的子 Agent，你都不用管。等你吃完之后回去刚好验收。你看看这个效果，这么多页图文并茂，分析得还非常好，这给我三千我可能都做不出来，那你就可以直接转给老板。

最后企业老板们也省心了。因为团队版的豆包工作权限、额度和数据都可以统一管理，飞书里面员工看不到的，他也看不到；AI 额度是老板分配的。最重要的是，做的成果和数据都可以落回飞书，个人的经验可以沉淀成团队的资产。
