**作者：**克莱加德

腾讯最近开源了一项面向 AI Agent 的共享记忆方案。它可以连接电脑中的多种 Agent 工具，让它们共用同一个记忆库，从而在不同任务之间顺畅交接工作上下文。

## 核心功能

-   统一管理多种主流 AI 工具的对话历史。
-   让不同工具共享同一份个人信息与长期记忆。
-   自动调用此前记录过的项目需求、代码规范和个人偏好，无需反复交代背景。
-   支持 Mac 桌面端和命令行环境，使用方式较为灵活。

## 记忆如何工作

![[笔记同步助手/images/2ccc049a17934ca839d99042ba654b0e_MD5.jpg|项目介绍画面，展示多种 AI Agent 工具连接并共享同一记忆库的示意图。]]

项目介绍画面，展示多种 AI Agent 工具连接并共享同一记忆库的示意图。

该方案并非简单保存全部聊天记录，而是通过腾讯的 **MemOS Memory** 记忆框架自动提炼关键信息，并关联相关上下文。这样既能维持任务连续性，也能控制存储空间占用。

对于需要长期推进的任务尤其有用：Agent 可以继续调用此前形成的记忆，减少重复描述上下文所消耗的时间和 Token 成本。

## 本地优先与数据安全

记忆数据以本地优先的方式存储，数据保留在用户自己的设备中，不依赖不断重复上传和说明个人背景，能够提升隐私可控性。

当 Claude Code、Cursor、Codex 等不同 AI 工具被用于同一项目时，共享记忆库可以把分散的对话与上下文汇总起来。用户只需向新的 Agent 说明当前任务，已有信息便能被调用，工作交接更加顺畅。

## 适用场景

-   同一项目中交替使用多个 AI 编程或办公 Agent。
-   需要长期持续推进、涉及大量上下文的复杂任务。
-   希望统一保留项目规范、偏好和工作记录的个人用户。
-   希望减少重复提示、降低 Token 消耗并提升工具切换效率的用户。

## 全文整理

腾讯最近又开源了一项实用项目，能够让电脑中的各种 Agent 工具共享同一份记忆库，从而实现各个 Agent 之间的工作完美交接。

这个项目可以统一管理 WorkBuddy、Claude Code、Cursor 等十种主流 AI 工具的对话历史，让所有工具共享同一份个人信息。你曾向某个 AI 工具说明的项目需求、代码规范和个人偏好，其他工具都能直接调用，不必再反复交代。

项目采用本地优先的存储方式，能够保障数据安全，Mac 桌面端和 CLI 均可使用。其底层依托腾讯的 MemoryOS 记忆框架，并非简单保存聊天记录，而是会自动提炼关键信息、建立信息关联，并在长期任务中持续保留上下文，同时控制存储空间占用。

跨工具调用记忆的准确率非常高，处理长期任务时不再需要反复补充上下文，Token 成本最多可节省三分之一。
