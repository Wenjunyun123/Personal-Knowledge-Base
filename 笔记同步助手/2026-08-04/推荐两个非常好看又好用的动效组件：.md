# 推荐两个非常好看又好用的动效组件：

## 推荐两个非常好看又好用的动效组件

### 一、动态边界光束

Animated border beam

-   安装：`npm install`
-   提供 Usage、Playground、State 等模块
-   状态支持：Listening、Breathing、Shaping
-   尺寸可调，例如 64px、20px

### 二、动态思考球

Animated thinking orb component

通过 npm 安装：

```
npm install thinking-orbs
```

组件会循环展示以下几种状态文字：

-   Thinking…
-   Solving…
-   Working…
-   Searching…
