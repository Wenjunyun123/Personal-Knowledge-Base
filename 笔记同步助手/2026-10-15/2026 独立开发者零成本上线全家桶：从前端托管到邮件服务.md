## 一、前端托管

-   **Cloudflare Pages**：可直接构建前端项目并提供二级域名访问；**带宽不受限制**，且**可用于商用**。
-   **Vercel**：同样可直接部署前端项目并提供二级域名；更适合非盈利项目（如个人博客、作品集），官方明确说明商用需升级至 Pro 方案。

使用方式：现在无需手动执行部署步骤，直接告诉你的 AI Agent「把项目部署到某个工具」，后续工作由 AI 完成。下面介绍的工具使用方式同理。

## 二、后端部署

-   **Cloudflare Workers**：每天 **10 万次免费请求**，且**无带宽限制**。
-   **Supabase**：BaaS（后端即服务），开箱即用；不限制 API 请求数量，但有 **5GB 流量限制**。

如果流量真的达到受限量级，说明产品已有市场，可以开始投入一些成本。

## 三、数据库

-   **Supabase**：提供 PostgreSQL 关系型数据库，每个项目数据限制 **500MB**，前期完全够用。
-   **Cloudflare D1**：支持 **10 个数据库**，总存储空间 **5GB**；每日 **500 万行读**、**10 万行写**。
-   **Turso**：支持 **100 个数据库**，总存储 **5GB**；按月更新读写额度——每月 **5 亿行读取**、**1000 万行写入**。

## 四、存储

-   **Supabase**：提供 **1GB 免费存储空间**，单文件上限 **50MB**。
-   **Cloudflare R2**：提供 **10GB 存储空间**，作为初期存储绰绰有余。

## 五、二次认证

-   **Supabase**：提供 **5 万月活用户（MAU）**。
-   **Clerk**：同样提供 **5 万月活用户**。

这两个额度都足够覆盖独立开发者前期使用。

## 六、邮件

-   **Resend**：每天支持 **100 封邮件**，配置简单，但**需要自备域名**。
-   此外，国内一些大厂也提供相应的免费邮件额度，可按需选用。

## 全文整理

一分钱不花如何搞定独立开发前期的前端托管、后端部署、数据库、存储、二次认证、邮件功能？本期视频全程无广，就来聊聊独立开发者如何零成本完成自己项目的初次上线，尽可能降低独立开发的试错成本。还是老规矩，文档已经整理完毕。

### 第一部分：前端托管

前端托管主要有 Cloudflare Pages 以及 Vercel 这两个工具可以选择。它们能做的事情都是直接把一个前端项目构建到对应的平台上，然后会给到二级域名直接可访问。区别是：Cloudflare Pages 带宽不受限制，并且可以商用；Vercel 更适合非盈利项目的部署，比如自己的博客、项目作品集等等，因为它明确写了商用需要升级到 Pro。Cloudflare 真是大善人。使用的话，现在不需要手动一步步去做了，你只需要和你的 AI Agent 说将我的项目部署到某个工具上，AI 会帮你完成接下来的工作。下面要介绍的这些也都是一样。

### 第二部分：后端部署

后端可以使用 Cloudflare Workers，或者直接用 Supabase 这种开箱即用的后端服务。Supabase 我之前也在视频中单独介绍过了，不限制 API 请求数量，但是有每月 5GB 流量的限制。不过如果真到了这个量级，说明这个产品有市场，就可以开始投入一些成本了。Cloudflare Workers 提供了每天十万次的免费请求，并且没有带宽限制，大善人真没话说。

### 第三部分：数据库

数据库可以使用 Cloudflare D1、Supabase 以及 Turso。Supabase 提供 PostgreSQL 关系型数据库，每个项目的数据限制是 500MB，前期使用肯定是够了。Cloudflare D1 支持十个数据库，总存储空间是 5GB，但每天有五百万行读和十万行写的限制。另外还有一个叫 Turso 的工具，支持一百个数据库，一共 5GB 的存储空间，它是按月更新读和写入的，每月读取五亿行，每月写入一千万行。

### 第四部分：存储

存储还是上面的老朋友了：Cloudflare R2 和 Supabase。Supabase 提供了 1GB 的免费存储空间，单文件的上限是 50MB。R2 提供了 10GB 的存储空间，作为初期的存储也是绰绰有余。

### 第五部分：二次认证

认证的工具可以使用 Supabase 或者 Clerk。其中 Supabase 提供了五万的月活用户数，Clerk 也提供了五万的用户数，足够独立开发者前期使用了。

接下来可能用得比较多的还有邮件。邮件的话可以使用 Resend，每天支持一百封邮件，API 比较简单，但是需要自己有域名。另外国内的一些大厂也有对应的邮件额度。

以上差不多就是一个独立开发者在产品上线前几乎能用到的工具了。互联网上确实还是有大善人存在的。
