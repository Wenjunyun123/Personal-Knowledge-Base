# 机器学习学习总结

## 第一章：机器学习概述

### 1.1 人工智能三大概念

#### 人工智能（AI）
- 定义：用计算机模拟人脑，让计算机能够像人类一样理性的思考、行动
- 目标：构建智能系统

#### 机器学习（ML）
- 定义：机器自动学习，不是人为规则编程
- 特点：从数据中自动学习规律

#### 深度学习（DL）
- 定义：深度学习，也叫深度神经网络，大脑仿生
- 特点：设计一层一层的神经元模拟万事万物

#### 三者关系
- AI包含ML，ML是AI的一种实现途径
- DL是ML的一种方法，属于ML的子集
- 层级关系：AI > ML > DL

### 1.2 机器学习发展三要素

1. **数据**：训练和学习的基础
2. **算法**：从数据中提取规律的方法
3. **算力**：
   - CPU：适合I/O密集型任务
   - GPU：适合矩阵运算和计算密集型任务
   - TPU：专门针对神经网络训练设计的处理器

### 1.3 常见术语

#### 样本（Sample）
- 一行数据就是一个样本
- 多个样本组成数据集
- 有时被称为一条记录

#### 特征（Feature）
- 一列数据就是一个特征
- 有时也被称为属性
- 是对预测结果有用的属性

#### 标签/目标值（Label/Target）
- 模型要预测的那一列数据
- 在分类任务中是类别
- 在回归任务中是连续值

#### 数据集划分
- **训练集（Training Set）**：用来训练模型的数据集
- **测试集（Testing Set）**：用来测试模型的数据集
- 常用比例：8:2、7:3

### 1.4 算法分类

#### 有监督学习
- **定义**：输入数据由输入特征值和目标值组成，即训练数据有标签
- **特点**：需要人工标注数据

**分类**：
- 目标值不连续
- 包括二分类、多分类任务

**回归**：
- 目标值连续
- 预测具体的数值

#### 无监督学习
- **定义**：输入数据没有被标记，没有标签
- **特点**：
  - 训练数据无标签
  - 根据样本间的相似性对样本集进行聚类
  - 发现事物内部结构及相互关系
- 不需要标注数据

#### 半监督学习
- **工作原理**：
  1. 让专家标注少量数据，利用标记的数据训练出一个模型
  2. 利用该模型去套用未标记的数据
  3. 通过对比分类结果与模型结果，进一步改善模型
- **优势**：可大幅降低标记成本

#### 强化学习
- **定义**：机器学习的一个重要分支
- **应用场景**：AlphaGo围棋、各类游戏、对抗比赛、无人驾驶
- **基本原理**：通过agent、环境状态、行动、奖励四个要素，agent根据环境状态进行行动以获得最多的累计奖励
- **例子**：小孩学走路的过程

### 1.5 机器学习建模流程

1. 数据获取
2. 数据预处理
3. 特征工程
4. 模型训练
5. 模型评估
6. 模型优化
7. 模型部署

### 1.6 特征工程

#### 定义
- 利用专业背景知识和技巧处理数据，让机器学习算法效果最好
- "数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限而已"

#### 特征提取
- 从原始数据中提取与任务相关的特征
- 构成特征向量
- 将文本、图片等非行列形式的数据转换成行列形式

#### 特征预处理
- 将不同单位的特征数据转换到同一个范围内
- 使训练数据中不同特征对模型产生较为一致的影响
- 解决量纲问题

#### 特征降维
- 将原始数据的维度降低
- 会丢失部分信息，但需保证数据的主要信息保留下来
- 原始数据会发生变化，不需要了解数据本身的含义

#### 特征选择
- 从特征中选择出重要特征
- 根据指标选择特征子集
- 特征选择不会改变原来的数据

#### 特征组合
- 把多个特征合并成一个特征
- 通过加法、乘法等方法将特征值合并

### 1.7 模型拟合问题

#### 拟合
- 表示模型对样本点的拟合情况

#### 欠拟合
- **表现**：模型在训练集上表现很差，在测试集上也表现很差
- **原因**：模型过于简单

#### 过拟合
- **表现**：模型在训练集上表现很好，在测试集上表现很差
- **原因**：
  - 模型太过于复杂
  - 数据不纯
  - 训练数据太少

#### 泛化
- 模型在新数据集（非训练数据）上的表现好坏的能力
- 泛化能力越强，模型越好

#### 奥卡姆剃刀原则
- 给定两个具有相同泛化误差的模型，较简单的模型比较复杂的模型更可取

## 第二章：KNN算法

### 2.1 KNN算法简介

#### 算法思想
- K-近邻算法（K Nearest Neighbor，简称KNN）
- 核心思想：根据"邻居"来推断类别
- 如果一个样本在特征空间中的k个最相似的样本中的大多数属于某一个类别，则该样本也属于这个类别

#### 样本相似性
- 样本距离越近则越相似
- 利用距离度量相似性

### 2.2 K值的选择

- K值过小：容易受噪声影响，导致过拟合
- K值过大：会忽略局部特征，可能导致欠拟合
- 需要通过交叉验证等方法选择最优K值

### 2.3 KNN的应用方式

#### 分类问题处理流程
1. 计算未知样本到每一个训练样本的距离
2. 将训练样本根据距离大小升序排列
3. 取出距离最近的K个训练样本
4. 进行多数表决，统计K个样本中哪个类别的样本个数最多
5. 将未知样本归属到出现次数最多的类别

#### 回归问题处理流程
1. 计算未知样本到每一个训练样本的距离
2. 将训练样本根据距离大小升序排列
3. 取出距离最近的K个训练样本
4. 计算这K个样本的目标值的平均值
5. 将平均值作为未知样本的预测值

### 2.4 API介绍

#### 分类API
```python
sklearn.neighbors.KNeighborsClassifier(n_neighbors=5)
```
- n_neighbors：int, 可选（默认=5），k_neighbors查询默认使用的邻居数

#### 回归API
```python
sklearn.neighbors.KNeighborsRegressor(n_neighbors=5)
```

### 2.5 距离度量方法

#### 欧氏距离
- 最常用的距离度量方法
- 计算公式：两点之间的直线距离

#### 曼哈顿距离
- 也称为城市街区距离
- 计算公式：两点在各坐标轴上的距离之和

#### 切比雪夫距离
- 各坐标轴距离的最大值

#### 闵可夫斯基距离
- 是对多个距离度量公式的概括性表述
- 欧氏距离和曼哈顿距离都是其特例

### 2.6 特征预处理

#### 为什么需要归一化、标准化
- 特征的单位或大小相差较大时，容易影响（支配）目标结果
- 使得一些模型（算法）无法学习到其他特征
- 需要将所有特征统一到同一尺度

#### 归一化（Min-Max Scaling）
- 将数据映射到[mi, mx]（默认[0,1]）之间
- API：`sklearn.preprocessing.MinMaxScaler(feature_range=(0,1))`
- **特点**：容易受到异常数据的影响，鲁棒性较差，适合传统精确小数据场景

#### 标准化（Standardization）
- 转换为均值为0、标准差为1的标准正态分布的数据
- API：`sklearn.preprocessing.StandardScaler()`
- **特点**：对异常点不敏感，具有较好的鲁棒性，适合大部分场景

### 2.7 鸢尾花分类案例

#### 数据集介绍
- 机器学习领域的经典数据集
- 包含150条鸢尾花信息
- 每种50条，共三种：Versicolour、Setosa、Virginica
- 四个特征：花萼长度、花萼宽度、花瓣长度、花瓣宽度

#### 实现步骤
1. 加载数据集
2. 数据展示和可视化
3. 数据集划分（训练集、测试集）
4. 数据标准化
5. 模型训练
6. 模型预测和评估

#### 关键代码结构
```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

# 加载数据
iris_data = load_iris()

# 划分数据集
x_train, x_test, y_train, y_test = train_test_split(
    iris_data.data, iris_data.target, test_size=0.2, random_state=22
)

# 数据标准化
transfer = StandardScaler()
x_train = transfer.fit_transform(x_train)
x_test = transfer.transform(x_test)

# 模型训练
estimator = KNeighborsClassifier(n_neighbors=5)
estimator.fit(x_train, y_train)

# 模型评估
score = estimator.score(x_test, y_test)
```

### 2.8 超参数选择的方法

#### 交叉验证（Cross-Validation）
- 将训练集划分为n份
- 每次取一份作为验证集，其余n-1份作为训练集
- 重复n次，每次使用不同的验证集
- 计算n次结果的平均值作为模型得分
- 原理：更全面地评估模型性能，减少偶然性

#### 网格搜索（Grid Search）
- 自动搜索最优的超参数组合
- 在指定的参数范围内尝试所有可能的组合
- 结合交叉验证评估每个组合的性能
- 选择性能最好的参数组合

#### 交叉验证网格搜索API
```python
from sklearn.model_selection import GridSearchCV

estimator = KNeighborsClassifier()
param_grid = {"n_neighbors": range(1, 10)}
estimator = GridSearchCV(
    estimator=estimator,
    param_grid=param_grid,
    cv=5
)
estimator.fit(x_train, y_train)

# 查看结果
print(estimator.best_score_)  # 最高平均测试得分
print(estimator.best_params_)  # 最优参数
print(estimator.best_estimator_)  # 最优估计器
```
